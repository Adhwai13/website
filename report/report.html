I. Introduction

A department website is the first place where students and parents look for information. In this assignment a simple website was created for the Department of Civil Engineering using HTML. It has a brown header with the department logo, a yellow menu bar, and six full-width sections: About Us, Academic Programmes, Our Faculty, Facilities, Enquiry Form and Contact Details. Alternate sections have a light background so that the reader can easily see where each section begins. The code was written in VS Code and the result was checked in Microsoft Edge.

II. HTML Document Structure

An HTML document has a fixed structure. The browser first reads the document type, then the head (information about the page) and finally the body (the content to display).

Listing 1. Skeleton of index.html
<!DOCTYPE html>
Declares the document as HTML5; without it the browser may use “quirks mode”.
<html>
The outermost (root) element of the page.
<head>
Holds metadata such as the character set, the title and CSS.
<title>
Sets the name seen on the browser tab.
<body>
Contains all visible elements of the page.

III. Headings, Paragraphs and Text Formatting

The page title is written with <h1> and the section titles with <h2>; HTML supports six levels down to <h6>. Text blocks are written in <p>. The formatting tags used are <strong> (important, bold), <b> (bold), <em> (emphasis, italic) and <ins>, which shows newly inserted text with an underline.

IV. Lists

Six subjects of the department are listed with an unordered list. <ul> creates the list and each <li> is a bullet point. (An ordered list <ol> would number them instead.) The facilities are written with a description list: <dl>, a term <dt> and its description <dd>.

Plate 2. Subjects shown as a bulleted list

V. Hyperlinks

A hyperlink is created using the anchor tag <a>, whose href attribute holds the destination. Three types are used: links to sections of the same page (#faculty), links to other websites – the college website, the Bureau of Indian Standards and AICTE – opened in a new tab with target="_blank", and a mailto: e-mail link.

Listing 4. Navigation and external links

VI. Images

The department logo, showing a building with pillars, is inserted at the left of the header with the <img> tag. src specifies the image file, alt provides a text alternative for visually impaired users and for broken images, and width and height fix its size at 80 × 80 pixels. The image is moved to the left with the CSS property float: left.

Listing 5. Department logo

VII. Tables

The faculty table lists five teachers. Besides the basic tags (<table>, <tr>, <th>, <td>), it uses <caption> for a title and <thead>/<tbody> to separate the heading row from the data rows.

Listing 6. Faculty table
Plate 3. Faculty table as displayed in the browser

VIII. Forms

The enquiry form is built with <form action="#" method="post">. Each field has a <label> joined to it by for/id. The name, e-mail and phone fields use type="text", type="email" and type="tel"; the phone field has pattern="[0-9]{10}" so only a 10-digit number is accepted. The course preference is a <select> list whose options are grouped into Undergraduate and Postgraduate using <optgroup>. Finally, Submit sends the data and Reset clears all the fields.

IX. Semantic HTML

Semantic elements are tags whose names explain their purpose. They replace a page full of anonymous <div> tags with meaningful blocks, which helps accessibility tools, improves search-engine results and makes the code easier to maintain.

ElementPurposeUsed for
<header>Introductory content at the top of a pageLogo, department name and slogan
<nav>A set of navigation linksYellow menu bar
<main>The unique main content of the pageAll six sections
<section>A thematic part of the content with its own headingAbout, Programmes, Faculty, Facilities, Enquiry, Contact
<footer>Closing content of the pageCopyright, author and “Back to top” link
